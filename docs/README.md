# Upstream website sources

This directory retains the original MacGames website sources for reference, including its
game guides and artwork. The site at [macgames.app](https://macgames.app/) belongs to the
original project by Tarik Caramanico; it is not this fork's website.

For **MacGames Fork**, use its [website](https://fjasensi.github.io/macgames/),
the repository's [README](../README.md),
[releases](https://github.com/fjasensi/macgames/releases),
[issues](https://github.com/fjasensi/macgames/issues) and
[contribution guide](../CONTRIBUTING.md).

The screenshots in `images/library-search.png` and `images/library-favorites.png` show this fork.
